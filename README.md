# Tomato Food Delivery App

**Tomato Food Delivery App** is a full-stack food delivery web application. Built with **Express.js, React, and MongoDB**, it allows users to browse a diverse menu, add items to their cart, and place orders with a seamless checkout experience, backed by a secure server and database layer.

---

# Architecture

Tomato follows a **Multi-Tier Client-Server Architecture (MERN Stack)**, providing a clean separation of concerns for scalability, maintainability, and security.

| Layer | Responsibility |
|---|---|
| Frontend | React application, menu browsing, and cart management |
| Backend | Express.js APIs and business logic |
| Database | MongoDB for users, menu items, and orders |
| Authentication | Secure login and signup |
